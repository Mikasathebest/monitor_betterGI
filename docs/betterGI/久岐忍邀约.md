## 1. 目标

全自动完成久岐忍邀约事件全部 5 个结局；每个结局最多试 3 次，3 次无法推进就**放弃邀约、记录原因，直接跑一条龙**（采矿 → 钓鱼 → 伊安珊材料）。画面卡住超 1 分钟退出重进；每步错误落盘，避免重复踩坑。

约束（用户明确要求）：

- 原神保持 **1920×1080 窗口化**，不许改分辨率/用 ShowWindow 拉伸游戏窗口。
- BetterGI 用**桌面快捷方式**启动；游戏路径 `e:\YS\miHoYo Launcher\games\Genshin Impact Game\YuanShen.exe`。
- 优先复用 BGI 内置「实时触发 → 自动邀约」，不要每步自己编程。
- 方案保持简单，复用已有经验。

运行：`.\.venv\Scripts\python.exe scripts\win\auto_hangout_shinobu.py <起始结局> <结束结局>`（如 `1 1`）。

BGI 脚本组配置（`set_hangout_config()` 写 `User/config.json`，改前必须先杀 `BetterGI.exe`，否则退出时被覆盖）：

```json
autoSkipConfig.autoHangoutEndChoose = "久岐忍结局1:期待之外的工资"  // 每结局改写
autoSkipConfig.autoHangoutEventEnabled = true
autoSkipConfig.autoHangoutPressSkipEnabled = true
```

**关键认知：内置自动邀约（AutoSkipTrigger）只自动选对话选项，不负责传送/接任务。** JS 必须先把角色送到 NPC 面前按 F 触发对话，之后才交给内置自动邀约。

## 3. 已验证可行的部分

- `genshin.Tp(x,y)` 传送后追踪距离从 1399m → 67~91m，**传送这一步稳定可用**。
- JS 可调用：`keyDown/keyUp/keyPress`、`moveMouseBy`、`click`、`wheel`、`genshin.Tp`、`genshin.ReturnMainUi`；OCR 用 `captureToRecognizeDet` + `RecognitionObject.Ocr(...)`。
- 结局判定：底部台词区 OCR 命中「达成结局」等，且连续 2 次 + 监督满 120s（防误判）。
- 结果日志约定：`NAV_RESULT: STARTED/ENDED/FAILED`、`RESTART: n`、`ERROR_LOG: step|msg|timestamp`；错误持久化 `AutoHangoutShinobu/errors.json`，Python 启动时读取展示。

## 4. 踩坑清单（务必复用，别再犯）

1. **BGI 坐标系反直觉（最致命）**：`GiWorldPosition.cs` 中 `X => Position[2]`、`Y => Position[0]`。JS 调 `genshin.Tp(px,py)` 时 **px = tp.json 的 position[2]，py = position[0]**。传反会把角色扔进海里。
   - 稻妻城锚点 id306（近，约 67m）：position[-3218.6, 265, -4495.0] → `Tp(-4495.035, -3218.596)`
   - 稻妻城锚点 id242（北/高处屋顶，约 91m）：position[-3050.2, 247, -4400.3] → `Tp(-4400.3, -3050.2)`
2. **稻妻城是立体地形**：两个锚点一个在水边低洼、一个在高台屋顶，到奉行所有台阶/栏杆/高差。BGI 的 `AutoTrackPathTask` 只读取预制的 `log/way/way2.json` 沿路径点走，**没有「追踪任务黄标自动跑到 NPC」的 API**；JS 里也没有 Track 类接口。盲目 8 方向奔跑会下水、卡栏杆、撞岩壁（已多次掉海被 Lv90 怪打、输入全阻塞）。
3. **卡死兜底**：角色水中濒死/过场「注意敌人」时 M/ESC/点击全失效，只能 `taskkill /F /IM YuanShen.exe` 再连 BGI 一起重启。
4. **直接启动 YuanShen.exe 第二次可能卡登录背景**（蓝天柱子，5~10 分钟无「进入游戏」）：第一次能进多因启动器 HYP 在跑提供登录 SDK。对策是启动后**完全不打扰、安静等 ≥5 分钟**，频繁点击/抓窗口反而干扰登录。
5. **独占全屏截图**：普通 `CopyFromScreen` 只能截到 IDE/桌面（黑屏）；必须用 `grab_game.ps1` 的 `PrintWindow(handle, hdc, 3)`。
6. **OCR 误匹配**：左上角常驻任务追踪「前往奉行所与上杉对话」会被当成 NPC 交互提示。已加过滤：真正交互名在屏幕中部，判定 `r.x >= 500`（旧版条件 `!(x<520 && y<480)`）。
7. **聚焦游戏窗口**只用 `WScript.Shell.AppActivate(pid/"原神")`，禁止 ShowWindow(3/9) 改窗口大小。
8. **改 config.json 前先 `taskkill BetterGI.exe`**。
9. 启动器「开始游戏」按钮在客户区截图外，UI 点击不可靠 → 直接启动 exe。
10. 强杀 BGI 后若键盘仍在移动，用 `keybd_event(...,KEYEVENTF_KEYUP=2)` 对 W/A/S/D/空格补发抬起。
