## 3. 树脂语义（源码实证，2026-09-15）

**`MinResinToKeep`（一条龙配置，当前=1）是"合成台保留 N 个原粹树脂不转化"，与浓缩树脂库存无关**（`GoToCraftingBenchTask.cs`：`合成次数 = min((原粹 - MinResinToKeep) / 60, 5 - 浓缩库存)`，**每个浓缩消耗 60**，整除向下取整）。

**2026-10-12 用户决策：3 → 1，尽量多合成**。合成后剩余原粹 = 1~60（不会留超过 60），除非浓缩已到 5 个上限。设 0 不行：源码 `MinResinToKeep > 0` 才走按数量合成的分支，0 走另一分支只点一次确认。改前 3 时 119 原粹只合 1 个、剩 59；改后 121 原粹合 2 个、剩 1，119 仍合 1 个（119-1=118，不够 120）。

**地脉花领奖优先用浓缩树脂**（`AutoLeyLineOutcropTask.cs::TryUseRewardResinOnce`）：原粹不空时候选顺序也是 浓缩 → 须臾(开关) → 原粹 → 脆弱(开关)。**没有"保留 N 个浓缩"的配置项**。

**2026-09-15 用户决策：接受现状**——浓缩刷地脉=双倍领取，与烧原粹总收益相同，体力零浪费，只是不攒浓缩库存。若日后真想保留库存，唯一路径是改源码（`TryUseRewardResinOnce` 解析浓缩数量 ≤N 则跳过）重新编译，需先验证奖励弹窗 OCR 是否含数量文本。

## 4. 战斗策略（地脉花/大组通用）

当前策略 `User\AutoFight\培养队轮换.txt`（按**游戏内队伍名**匹配，v3 2026-09-15）：

```
玛薇卡 e(hold),check          # 火神长E转圈挂火
奥黛塔 e,q,e,check
阿罗夏 e,q,check
玛薇卡 q,check
桑多涅 click(middle),e,charge(2.2),charge(2.2),q,check   # 木偶: 镜头回正+E+长按重击×2+Q
```

语法（出自群友分享`万能战斗策略.txt`）：`charge(秒)`=按住普攻时长（长按重击）；`e(hold)`=长按战技；`click(middle)`=镜头回正；`check`=敌人死光提前结束本行；`moveby(x,y)`=移动视角。

配套设置（config.json，2026-09-15 已开）：`autoFightConfig.enableCombatTargeting=true`（战斗索敌，治视角卡死）、地脉花 `fightConfig.seekEnemyEnabled=true`（多波次主动寻敌）。`rotateFindEnemyEnabled` 保持关闭（万能策略作者警告：转速过快会卡检测/乱转）。

**调参**：若木偶重击仍像短按，调大 `charge(2.2)` 的秒数；若转火慢，在行间加 `moveby`。

## 6. 月卡（空月祝福）漏领事件与修复（2026-09-15）

**事件**：04:36 会话正常进门+一条龙，但当天月卡 90 原石未到账，用户 09:33 手动补领。BGI 日志对月卡**零记录**——一条龙的 returnMainUi Esc 关闭祝福弹窗不等于领取（或弹窗出现时序与任务导航错开）。

**原修复**：在 `树脂监控/main.js` 开头调用 `genshin.blessingOfTheWelkinMoon()`。

**2026-10-12 读源码更正：这个调用对 04:15 场基本是空操作**。`BlessingOfTheWelkinMoonTask` 只在服务器时间 **03:55~04:05** 才检测（为"在线跨 4 点"设计），04:15 后登录时它直接返回，日志里的"检查/领取完成"并不代表领到。PathExecutor/TpTask/ScriptService 里内置的月卡检查也是同一个任务，同样不生效。

**早场真正收月卡的两道关**（登录即弹，每天必有）：
1. **BGI 登录触发器 `GameLoadingTrigger`**（`autoEnterGameEnabled=true`）：截图器启动后 5 分钟内每 2s 检查一次，自动点「点击进入」、**空月祝福界面、原石界面**（无时间窗限制），识别到主界面后自停。session_online §4 先起截图器 → BGI `linkedStartEnabled` 联动拉起游戏，所以触发器全程在线（证据：早场 cycle_log 没有"游戏已直起"，§7 重起截图器时"截图按钮未找到"=截图器早已在跑）。
2. **`door_clicker2` 盲点中心**（6s/次 × 180s）：空月祝福和原石界面都是"点任意处继续"，兜底。
3. 若仍挡住一条龙（队伍"未知角色"/打开大地图失败），§9.5 补跑前先点 3 下中心再 ESC。ESC 关不掉月卡界面。

**审计方法**：GameLoading 只写 Debug 不写日志，月卡是否到账日志里看不出来。看早场一条龙是否"队伍识别正常 + 打开大地图正常"；补跑截图 `od_fail_*.png` 里若是月卡界面，说明两道关都漏了。
