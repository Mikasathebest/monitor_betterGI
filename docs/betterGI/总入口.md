## 铁律速查（细节见各分册）

0. **每次运行自动化前先读 [错题本.md](错题本.md)**，犯过的错不许犯第二次
1. Windows 脚本部署用 `scripts/win_sync.py push <文件名>`（内部走 to_win 单 BOM + CRLF）；改完先 `win_sync.py diff` 确认仓库与 Windows 一致；计划任务必带 `-NoProfile -NonInteractive`
2. 一次性调试任务必须 `/sd 01/01/2099` 防误触发，用完即删
3. 读 BGI 日志用 `FileStream + FileShare.ReadWrite`（独占锁）；判活性看内容时间戳不看 LastWriteTime
4. 路线文件只认 `User\AutoPathing\`（MapPathing 是遗留目录）；引用不存在的路线 = 0.003s 假成功
5. 会话期间不要手动触发可见控制台任务（抢焦点 → BGI 暂停）；看门狗等后台任务用 wscript 隐藏
6. 改组文件只追加/删尾，中间插入会让书签索引错位（错位影响仅一轮，可自愈）

## 代码目录

| 路径 | 内容 |
|---|---|
| `scripts/agent/` | Mac 端 LLM 监控 Agent（`bgi_agent.py`）、CV 截图分析、定时调度 `daemon.sh` |
| `scripts/bgilog.py` | BGI 日志解析：材料拾取统计、路线假跑/缺失识别、历史基线对比（Agent `material_report` 用它） |
| `scripts/win_sync.py` | Windows 脚本部署（push）与漂移检查（diff） |
| `scripts/win/prod/` | **生产链路**脚本（会话上下线、看门狗、进门、截图、书签、日志导出）——改这里要 push 并 diff |
| `scripts/win/setup/` | 一次性系统配置（计划任务注册、Update 加固、自动登录、组文件改造） |
| `scripts/win/tools/` | 可复用的只读诊断（tail/grep 日志、任务状态、窗口枚举、收益统计） |
| `scripts/win/archive/` | 历次排查的一次性脚本、已放弃的邀约自动化——只作参考，不再部署 |
| `data/bgi_stats/` | 每日材料/路线统计 JSON（路线基线） |
