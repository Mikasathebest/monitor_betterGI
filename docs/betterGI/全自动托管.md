## 7. 体力监控与自动清体力（树脂监控）

**需求**：体力（原粹树脂）> 150 时自动去打摩拉/经验书地脉花，防止溢出浪费。

**实现**（纯 JS + 内置任务，无 UI 自动化）：

- 自研 JS 脚本 `User/JsScript/树脂监控/`：
  1. `genshin.returnMainUi()` → `keyPress("M")` 开地图；
  2. 模板匹配 `assets/original_resin.png`（40x40 图标，取自 BGI 源码资产）定位树脂栏；
  3. `RecognitionObject.ocr(icon.x, icon.y, 200, 40)` 读 "xxx/200" 取当前值；
  4. `>= 阈值(默认150)` → `dispatcher.runAutoLeyLineOutcropTask()` 调 BGI **内置地脉花任务**，耗尽模式 + 先合浓缩树脂（3 倍领取），不动脆弱/须臾树脂；
  5. 未达阈值 → 打日志退出（约 10 秒开销）。
- **挂载方式**：以 `Javascript` 类型任务插入 `采矿` 组每 40 条路线之后（19 处）+ 队尾；`材料收集` 组同理（5 处）。采矿中途到点自动检查，达标就暂停采矿去清体力，清完继续采矿。
- 独立 `体力监控` 配置组：只含该脚本，随时可手动单跑一次。
- 可调参数（脚本设置页）：阈值 / 藏金之花(摩拉) 或 启示之花(经验书) / 国家（默认枫丹）。

**注意**：正在运行的队列是内存里的旧配置，树脂监控点位要**下次启动队列**才生效；脚本首次触发后看日志确认 OCR 读数正确。

**架构**（2026-09-14 v2 上线，替代 v1 的"跑完再休 4.5h"）：

```
全自动循环 配置组 (605 任务)
  ├─ 树脂监控 (上线先测体力, ≥150 先刷地脉)
  ├─ 材料收集 184 条 (打怪优先; 含嵌合胞 H002至冬嵌合翼骏狮东)
  ├─ 树脂监控

  ├─ 树脂监控
  ├─ 其他矿 299 条 (紫晶块108/水晶块144/虹滴晶42/星银5; 已删铁块12+魔晶矿290)
  │    (每 40 条插一个树脂监控)
  ├─ 钓鱼 34 条
  ├─ 树脂监控
  └─ Shell: cycle_offline.ps1 -Complete → 清书签 → 下线 → 排程 BGI_Online (+3h)
```

**3h/3h 循环**（自 perpetuating 计划任务链）：

- `BGI_Online` → `online_start.ps1`：起 BGI（经 `BetterGI_Run` 交互任务）→ 游戏联动启动 → 等 4 分钟 → `uia_start_group.ps1` 选大组点"运行"（**书签生效，从断点续跑**）→ 排程 `BGI_Offline` (+3h)
- `BGI_Offline` → `cycle_offline.ps1`：`set_bookmark.py` 从日志找最后路线 → 写 `nextScheduledTask` 进 config.json → 杀游戏+BGI → 排程 `BGI_Online` (+3h)
- 大组跑完（Shell 任务）→ `cycle_offline.ps1 -Complete`：清空书签，下轮从头（矿石已刷新）

**进度书签原理**（关键发现）：

- `config.json` 的 `nextScheduledTask` = `List<(组名, 索引, 文件夹, 文件名)>`，BGI 加载组文件时把它标成任务的 `NextFlag`；点"运行"时 `GetNextProjects()` 会跳过书签之前的所有任务（`ScriptControlViewModel.cs:1992`）。
- 所以"杀进程 → 写书签 → 重启 → 点运行"= 断点续跑，不会每次从头白跑空矿点。
- JSON 形状：`[{"Item1":"全自动循环","Item2":123,"Item3":"文件夹","Item4":"名.json"}]`（STJ 序列化 ValueTuple）。

**每日 4:30 日常**（独立链路，v2 更新）：

- `BGI_Daily_0430`（每天 04:30）→ `daily_0430.ps1`：
  1. 游戏没开（休息窗口）→ 起 BGI+游戏 → 等 4 分钟 → F9 一条龙 → **15 分钟后关游戏回到休息状态**；
  2. 游戏在跑但队列忙（日志 15 秒内有写入）→ **跳过**；
  3. 游戏在跑且空闲 → 直接 F9。
- 一条龙 `默认配置`：只启用 **合成树脂**（枫丹合成台）+ **领取每日奖励**（枫丹协会交委托 + 纪行）。月卡 90 原石登录即弹窗，一条龙开头 returnMainUi 自动收掉。
- 合成 2 个浓缩 = 80 树脂转化 → 冒险之证历练点自动清委托。
